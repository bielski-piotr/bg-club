# @bg-club/score-pad

Web componenty `<score-pad>` (notes 3D) i `<score-pad-editor>` (kreator notesu) w trybie klubowym.

Na razie pakiet jest pusty. Źródła z `digital-scorepad-poc` (`example/score-pad/score-pad/src/`, wersja 2.4.0, commit `e6b7dd2`) przenosi zadanie [013] zgodnie z PRD §8.5: bez plików `dist/`, z Three.js z npm.
